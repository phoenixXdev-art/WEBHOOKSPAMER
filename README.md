# WEBHOOKSPAMER v1.0.0

A small educational project created for learning and experimenting with Discord webhooks.

## 📌 About
This project is shared for educational purposes and experimentation. The source code is included so users can explore how the program works, learn from the code, and build it on their own systems.

## 📦 Included
- `WEBHOOKSPAMER.exe` – compiled executable.
- Source code – available in the repository for learning and building locally.
